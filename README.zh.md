# 作业助手（AI Passport · DeepSeek Harness 插件）

把家长群里的作业截图变成清单，孩子在 AI Passport 上按住说话、一项一项计时。陪着孩子的是一个像素小机器人，会记住每类作业实际要做多久。

**有了这个插件，你不需要**：Python、DeepSeek API Key（直接用 Harness 里登录的账号）、任何语音密钥（默认机械哔嘟声）。

## 你需要准备

- 一台 **FoloToy AI Passport** 设备，和一根能传数据的 USB-C 线。
- **DeepSeek Harness 桌面版**（macOS Apple 芯片或 Windows 64 位），从 [deepseek.com/harness](https://www.deepseek.com/harness/) 下载并登录。
- 设备和电脑连同一个 **2.4G Wi-Fi**。

## 安装

**1. 装插件**：打开 DeepSeek Harness 的插件市场，搜索“作业助手”或 `albis-aipassport-homework`，点安装。也可以在终端运行：

```
dsh plugin --profile desktop add albis-aipassport-homework
```

装好后重启 Harness。第一次启动会在后台下载语音识别模型（约 230MB，国内镜像优先）。

**2. 给设备装作业助手固件**：设备出厂时没有作业助手程序。点插件页的“修改设备设置或刷机”，对 AI 说“帮我第一次给设备装上作业助手固件”。AI 会按开发说明下载本仓库的 `firmware/`、编译，并在**你同意后**刷机（也可以直接从 FoloToy AI Passport 玩法社区刷入）。刷完用“蓝牙配网-FoloToy AI PASSPORT”小程序给设备配网，然后设备屏幕上会出现一个 4 位**配对码**：到家长后台核对同样的数字，点“允许”就连上了。

> 固件里不写电脑名和令牌，设备靠“配对”连电脑，所以所有家庭可以用同一份固件。

**3. 确认连上**：配对后，插件页“运行状态”里的“设备”变成“在线”，设备上机器人的头灯变红，就说明装好了。**Harness 桌面版要一直开着**，设备才连得上。

## 更新

插件有新版本时，插件市场会提示“有更新”，点一下就能更新，然后重启 Harness。设备固件有更新时，在对话里让 AI 帮你更新固件（只刷程序区，不用重新配网）。

## 侧边栏页面

安装后 Harness 左侧会多一个“作业助手”入口（机器人图标），页面从上到下四块：①**打开家长后台**（主入口，旁边是和设备同款的像素小机器人：头灯红=设备在线、灰=没连上，服务没运行时机器人睡着）；②**让 AI 帮你改**：用于定制和维护，点了会开新会话并预填开头（接入自己的语音合成、修改统计报表、检查设备连接、修改设备设置或刷机，以及“开一个新对话”）；③**运行状态**四格（服务、设备、语音识别、机器人声音），有问题时出一条提示，可一键“让 AI 排查”；④**硬件操作说明**。设备地址、令牌、连接测试、刷机这类事都不放在页面上，交给对话处理。

## 怎么用

**家长，在 Harness 对话里：**
- 贴一张家长群的作业截图，说“今天的作业”——助手会按老师原文整理成清单，同步到设备。
- “数学改成 20 分钟”“把第 2 项挪到最前面”“删掉第 3 项”“清空今天的作业”。
- “作业助手状态”——看服务、语音识别和声音的状态。
- “看看各类作业平时要做多久”。

**家长，在网页后台：** 浏览器打开 `http://127.0.0.1:8787`（只能在这台电脑打开）。可以拖入截图、改清单、听孩子的录音、维护短语库、看用时记录。

**孩子，在设备上：** 按住确定键说话，松开发送。例如“今天有数学练习册 34 到 35 页，还有背古诗”“现在做数学”“数学做完了”。

## 设备怎么连

设备通过 Wi-Fi 在局域网里广播找到这台电脑（不用填电脑名或 IP），端口 8787，每次请求带自己的设备令牌。第一次连接要配对：设备屏幕显示 4 位配对码，家长后台（`http://127.0.0.1:8787`）同时弹出同样的数字，核对一致后点“允许”，电脑才给这台设备发令牌（设备自己保存，以后开机自动连）；不认识的设备点“拒绝”。连不上时，点插件页的“检查设备连接”让 AI 排查（常见原因：不在同一个 2.4G Wi-Fi、Mac 防火墙拦了连入）。

## 机器人的声音

默认是本地合成的机械哔嘟声，屏幕照常显示文字。想换，在插件设置里改 `voice.provider`：

- `azure`：微软 Azure 语音（示例）。填 `voice.azureKey`、`voice.azureRegion`。
- `custom`：自己的文件，`voice.customModule` 填绝对路径。**不会写？** 对 Harness 助手说“照 voice/azure.js 的写法，帮我接入 ×× 的语音合成”，写法见 `voice/README.md`。

## 孩子的年级

插件设置里的 `grade`（默认“五年级”）会用来估计作业时长、调整小机器人说话的方式。

## 隐私

- 孩子的录音只在本机识别，不上传。
- 发给模型的只有截图和文字；孩子的话只直接问模型，不进入 Harness 的智能体对话，也不会被当成操作电脑的指令。
- 数据在 `~/.dsh/homework-helper/`。

## 开发

```
npm install
npm test
```

- `DEV-GUIDE.md`：给 Harness 对话里的 AI 看的开发说明（项目文件、接入语音合成、修改统计报表、排查连接、改固件和刷机的步骤与规则，以及 AI Passport 官方硬件开发资料链接）。AI 通过对话工具 `homework_dev_guide` 读取，插件页“让 AI 帮你改”开的对话会先让 AI 读它。
- `firmware/`：设备固件源码，基于 [FoloToy/ai-passport](https://github.com/FoloToy/ai-passport)（MIT 协议）。不随插件包发布，需要时克隆本仓库。
- `lib/pairing.js`：设备配对（局域网发现、配对码、设备令牌）。
- `scripts/device-config.mjs`：开发调试用，把电脑名和令牌写死进固件；正常安装不需要。
